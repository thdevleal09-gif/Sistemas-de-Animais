# Sistemas de Animais

Projeto desenvolvido em C# e .NET 10
com o objetivo de praticar os quatro pilares
da Programação Orientada a Objetos.

## Conceitos praticados

- Abstração
- Encapsulamento
- Herança
- Polimorfismo

## Tecnologias

- C#
- .NET 10

## Funcionalidades

- Cadastro de animais
- Listagem
- Alimentação
- Emissão de sons
- Validação de dados

## Estrutura

Animal
├── Cachorro
├── Gato
└── Passaro
